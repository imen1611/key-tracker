Key & Fob Tracker

Xtreme Security Inc.

This app uses a Google Sheet as its live database. All records are stored there and shared across all managers in real time. You can also use demo mode to explore without setup.

1
Create a new Google Sheet named Key Fob Tracker. Create 3 tabs: Keys, AuditLog, Clients.
2
Keys row 1: Transit | KeyNumber | Type | Client | Location | Status | HeldBy | HeldByRole | PickupDate | LastCheckDate | ReturnedTo | Photo | Notes | AddedDate
AuditLog row 1: Timestamp | Action | KeyID | Guard | Note | Manager
Clients row 1: Name | ContactName | ContactPhone | ContactEmail | Address | Notes | AddedDate
3
Go to Extensions → Apps Script, paste the apps-script.gs file (updated version with deleteRow support), deploy as Web App (execute as Me, access Anyone). Copy the URL.
4
Paste the URL below and enter your name.
